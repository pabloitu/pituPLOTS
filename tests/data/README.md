# Test fixtures

Generated by `make_fixtures.py` from the real project data, and committed. The
tests use these files only; the script needs local data that is not in the
repository. `manifest.json` has a SHA-256 for every file, and `test_fixtures.py`
checks them and the 5 MB budget.

| Folder | Content |
|---|---|
| `lacq/` | SSM pattern window (25 x 25 cells), full event list, hazard map GeoTIFF, `calc_11_subset.hdf5` (OpenQuake datastore restricted to that window, 1 realization, site ids renumbered) |
| `chile/` | Grid and hazard subsets, cropped GeoTIFFs, trench and buffer shapefiles, fault subsets, `grid_capped.csv` (`in_buffer` plus 3 rate columns) |
| `new_zealand/` | Catalog crossing 180 deg, CSEP nodes window, testing region, NZ CFM subset in EPSG:2193 |
| `nrml/` | 5 simple-fault sources and 1 complex-fault source, NRML 0.4 |
| `catalogs/` | CSEP JSON catalogs and a ComCat CSV sample |
| `basemaps/` | Decimated RGBA GeoTIFF in EPSG:4326 |
| `regions/` | Iceland polygon, a high-latitude case |
| `natural_earth/` | Natural Earth subset, for offline tests |

`natural_earth/` follows the cartopy cache layout and `conftest.py` sets it as
`cartopy.config["pre_existing_data_dir"]`. It has coastline and land borders at
110m, 50m and 10m, and land and ocean at 110m and 50m. The 110m layers are
global. The 50m and 10m layers are clipped to `REGIONS` in `make_fixtures.py`
(Europe, South America, California, New Zealand), so a test at those scales has
to stay inside them, or its map will show missing coast. Natural Earth does not
version its download URLs, so `natural_earth_sources` in the manifest records
the SHA-256 of the source shapefiles. Natural Earth is in the public domain.
